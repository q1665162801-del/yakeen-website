## 使用说明

1. **这些图片仅作参考用途**，不可直接用于Yakeen网站
2. 参考方向：
   - 产品图片：参考拍摄角度、灯光效果、参数展示方式
   - 工厂照片：参考需要拍哪些角度的工厂照片
   - 工程案例：参考案例展示的页面结构和描述方式
3. 后续需要自行拍摄Yakeen的工厂和产品照片替换
